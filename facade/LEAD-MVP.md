# Ручная визуализация: приём заявок

Публичная версия каталога работает на GitHub Pages с доменом catalog.nashdvor.com.ua. `facade/lead.js` заменяет автоматическую обработку формой заявки. Модели, Python-сервер и редактор маски для этого режима не нужны.

Получатель: nash.dvor.office@gmail.com. Форма отправляет обычный multipart POST на FormSubmit; фото называется `attachment`. Не заменять отправку JSON/AJAX-запросом: для вложений используется документированный multipart-сценарий. Суммарный лимит фото — 10 МБ. В письме передаются фото, имя, телефон, город, площадь (если известна), предпочтительный способ связи, пожелания, выбранные панели с основами, толщинами, артикулами, ценами и исходной страницей.

Перед приёмом реальных заявок нужно активировать адрес по письму FormSubmit и проверить доставку пробной заявки с вложением. Сервис может показывать свою проверку перед отправкой; защита CAPTCHA не отключается. Страница thanks.html открывается через `_next` после обработки формы сервисом, а не по локальному нажатию кнопки. Пока активация и письмо с вложением не проверены, доставку нельзя считать подтверждённой.

При проверке 06.11.2026 FormSubmit вернул HTTP 522, поэтому тестовое письмо и активация не подтверждены. В форме есть резервная ссылка: открывает почтовую программу клиента с заполненными контактами и выбранными панелями; фото клиент прикрепляет к письму самостоятельно.

Фото и контакты передаются через FormSubmit в указанную почту; это явно указано в согласии клиента. Никаких обещаний автоматического результата, срока подготовки или хранения заявки в локальной базе нет. Обработку и дальнейший ответ выполняет команда вручную.

Документация сервиса: https://formsubmit.co/documentation (раздел File uploads).
