# Ручное уточнение примерки

Локальная версия: кнопка «Уточнити ділянки» в результате. После автоматического
отказа доступна кнопка «Виділити ділянки вручну»; в этом случае контур фасада обязателен.
Проверка формата, разрешения, резкости и экспозиции при загрузке не менялась.

## Инструменты

- Окно, дверь/гаражные ворота: обвести 3–32 точками по форме проёма вместе с рамами
  и откосами. Завершить кнопкой или повторным кликом по первой точке.
  Ранее сохранённые прямоугольные выделения также поддерживаются.
- «Інша ділянка»: обвести точками любой участок, который надо сохранить (балкон,
  растения, трубы). Это исключение из наложения, без присвоения класса окна/двери.
- Цоколь: поставить 2–16 точек по его верхнему краю в одном направлении, завершить контур.
  Полностью обратный порядок сервер нормализует автоматически.
  Между точками граница линейная, за крайними точками продолжается горизонтально.
  В пределах фасада всё ниже сохраняет исходный вид. Другой материал пока не выбирается.
- Контур фасада: 3–32 точки по периметру стены, завершить контур. Он заменяет
  автоматическую поверхность стены и ошибочно найденный автоматический цоколь.
  Если цоколь нужен внутри нового контура — указать его отдельной линией.
- Перемещение точек мышью, стрелками (Shift — крупнее); удаление области, отмена
  действия, очистка собственных выделений; увеличение фото. Незавершённый контур
  надо закончить либо отменить перед сохранением. Escape отменяет его внутри поля.

«Назад без змін» не отправляет координаты на сервер. «Оновити примірку» обновляет
все выбранные варианты. Новая маска полностью пересчитывается от исходных данных,
поэтому повторное редактирование не наслаивает фактуру на прежний результат.
Расчёт стоимости и его срок действия при редактировании готового результата сохраняются.
При восстановлении отклонённой примерки создаётся первый расчёт по обычным правилам.

Ручное редактирование не увеличивает confidence модели и не означает проверку
геометрии. Для четырёхугольного выпуклого контура без линии цоколя сохраняется
проективная плоскость; сложный контур использует приблизительную охватывающую
плоскость. Масштаб фактуры по-прежнему условный.

## Данные и обучение

Нормализованные координаты 0–1, типы элементов и необязательное согласие сохраняются
в SQLite `annotations`. Связь — UUID задания, без копирования контактов в разметку.
Текст согласия и время обновления записываются вместе с ним. По умолчанию согласие
выключено; для исправления картинки оно не требуется.

Фото, автоматическая финальная маска, доступная исходная маска стены, автоматические
исключения и последняя ручная маска находятся в закрытой папке задания. Результат
ручной правки — отдельная UUID-ревизия. После успешной замены предыдущая ручная
ревизия удаляется, автоматический результат сохраняется. Ошибка пересчёта оставляет
предыдущий результат. Параллельная обработка ограничена общим локальным LOCK;
устаревшая вкладка получает 409 и должна перечитать результат.

`review_status=pending`: пользовательские выделения ещё не являются эталонной
разметкой. Контур окна может включать стену; линия
цоколя требует проверки. Согласие, полученное по ссылке UUID, также требует
проверки перед использованием в обучении. Автоматического экспорта, публикации,
обучения весов или отправки снимков во внешнюю модель не добавлено.

В редакторе есть отдельное действие отзыва ранее сохранённого согласия, которое
работает без модели и загрузки текстур. Оно исключает текущую запись из будущего
отбора на обучение. Обучающих запусков в этой версии нет. Исправления и согласие
удаляются вместе с фото по исходному сроку задания; редактирование не продлевает его.

Для старых заданий может отсутствовать маска стены до удаления цоколя. Чтобы
восстановить ошибочно удалённую область такого задания, нужно обвести фасад.
Старый отказ также получает URL исходника, если сохранённый файл ещё существует.
При отказе доступен исходник, но не автоматическая визуализация.

## API

- GET `/api/facade/jobs/{id}` возвращает `editing`: revision, elements,
  trainingConsent, consentText; контакты не возвращаются.
- PUT `/api/facade/jobs/{id}/correction`: `{revision, elements, trainingConsent}`.
  Элемент: `{kind: "window"|"door"|"facade"|"plinth"|"exclude", points: [{x,y}, ...]}`.
  revision=null для первой правки. Всего до 64 элементов, один фасад и один цоколь.
  Пересекающийся контур, вырожденные, нечисловые и выходящие за кадр координаты
  отвергаются. Авторизация такая же, как у результата: владение непредсказуемой ссылкой.
  Повторная точка замыкания убирается перед проверкой. При ошибке сервер возвращает
  конкретный номер области и `invalidElements`; интерфейс выделяет её красным.
- DELETE `/api/facade/jobs/{id}/training-consent`: только отзывает согласие.
- GET `/api/facade/jobs/{id}/revision/{revision}/image/{name}`: только изображения
  текущей ручной ревизии. Исходник и текущая ревизия закрываются после истечения
  срока задания, с noindex, no-store и no-referrer.

Для публичного запуска по-прежнему нужны внешние ограничения частоты запросов,
объёма хранения и защита доступа к персональной ссылке. Текущая реализация локальная.
