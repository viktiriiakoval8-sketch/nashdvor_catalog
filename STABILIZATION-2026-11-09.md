После общего разбора добавлены `facade/textures.py` и команда
`python tools/prepare_facade_textures.py`. Все 14 внешних фактур скачаны заранее;
32 встроенные фактуры проверены. Повторная проверка с `--check` без сети:
**46/46 готовы**. Во время обработки больше нет загрузки фактур по HTTPS внутри
общей блокировки. Для внешних фактур проверяется локальная копия до создания задания;
если она отсутствует или повреждена, возвращается понятная ошибка 503.

Кэш привязан к URL, загруженные изображения проверяются до атомарного сохранения.
Неверный файл не становится готовой фактурой. Новые проверки охватывают повторное
использование, восстановление повреждённого кэша, ограничения размера и адресов,
а также отсутствие задания при недоступной фактуре.

Итоговый полный прогон после этой доработки: **112 passed**, 34,93 секунды.
Изменения локальные; для работающего сервера нужен перезапуск.
Кэш находится в исключённой из Git папке `.facade-data/texture-cache`.
При переносе на другую машину требуется повторная подготовка.

## Выполнено

- Разделены клиентский каталог `/` и экспериментальная автоматическая примерка `/lab`.
- `/result/{UUID}` снова загружает автоматическую примерку и редактор; существование и срок действия задания по-прежнему проверяются сервером.
- Локальный сервер обслуживает CSS/JS новой формы и Google-транспорт. Список разрешённых файлов остаётся явным: конфигурация, Code.gs, deployment.json, база и произвольные файлы недоступны через эти маршруты.
- Лаборатория получает только необходимые поля 46 панелей (67 648 байт JavaScript); фотографии загружаются отдельными запросами. Полный клиентский index.html размером 12 289 643 байта для открытия результата больше не нужен. Это размер файлов, не измерение времени загрузки; объём самих фотографий не уменьшался.
- Лаборатория закрыта от индексации. Результаты сохраняют no-store и no-referrer.
- Повторная отправка неизменённой почтовой заявки сохраняет идентификатор. Изменение содержимого, варианта товара или файла создаёт новый идентификатор даже при программном изменении полей.
- После ошибки чтения фото повторная попытка читает файл заново; успешное преобразование фото переиспользуется.
- Локальная форма явно объясняет, что Google-приёмник принимает заявки с домена каталога; контакты из локального просмотра не отправляются.
- Исправлен устаревший тест экспорта: он проверяет три категории примерки, а не весь расширенный каталог плитки.
- Обновлены инструкции и версия URL Google-транспорта для обновления клиентского кэша.
