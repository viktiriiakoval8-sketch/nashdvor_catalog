# Каталог термопанелей NASH DVOR

Один самостоятельный `index.html`: HTML, CSS и JavaScript без сборки и внешних скриптов. Интерфейс на украинском языке. Google Fonts необязательны: при отсутствии сети используются системные шрифты.

## Запуск

Откройте `index.html` в браузере или выполните из каталога проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

В облачной среде используйте существующий `/workspace/nashdvor_catalog`, не создавайте worktree и не клонируйте проект повторно.

## Данные

Все данные находятся в `const CATALOG` в начале скрипта. Инструкция над блоком объясняет добавление разделов, позиций, основ, толщин, цен, фото и контактов. Цены задаются ключами `основа_толщина`; отсутствующие сочетания отключены. `phone` — основной телефон, `phones` — дополнительные. Телефоны компании показаны в подвале. Формы заказа, запросы в мессенджеры и калькулятор площади удалены: это информационный каталог.

## Источники ассортимента

54 панели в четырёх разделах: керамогранит (23), польский клинкер (9), под покраску (8), имитация клинкера (14). Углы, откосы и посторонние товары не включены.

Основной источник вариантов — `53036adf9439ec9d6d7375fbfcb4941f.xlsx`: импортированы 344 отдельных модификаций. 69 строк базальта исключены по прямому указанию владельца (он не производится), 3 строки уголков не относятся к текущим панелям. Сопоставление строк, артикулов, цен и единиц сохранено в `print/variant-import-audit.json`.

- Керамогранит: пенопласт 50/80/100/150/200 мм; пенополистирол 30/50/80/100 мм; стеклосетка без утеплителя. У всех 23 панелей известны цены всех 10 сочетаний, **грн за панель 0,564 м²**. «Пінополістирол» сохранён под названием из выгрузки, без неподтверждённого переименования в XPS.
- Под покраску: пенопласт 20/30/40/50/80/100/120/150/200 мм, **грн/м²**, все 72 цены. Четыре позиции без фотографий исключены по просьбе владельца.
- Имитация клинкера: цены на все 42 варианта сверены с живыми карточками nashdvor.com.ua — **990 / 1060 / 1100 грн/м²** для 50 / 80 / 100 мм соответственно. Полезная площадь панели 0,54 м² остаётся характеристикой, не единицей цены. Основа оставлена без переименования по прежнему указанию владельца.
- Польского клинкера в новом экспорте нет. Сохраняется предыдущий прайс 01.09.2026: 45 цен за м² для пенопласта 50–200 мм; стеклосетка без утеплителя упомянута в описании, но 9 цен на неё по-прежнему неизвестны.

Всего 389 известных цен. Ни цены, ни площадь панели не округляются до целых в исходных данных. Для новых цен дата актуальности в экспорте не указана. Цены за панель не выдаются за цены за м² и не объединяются с ними в одной таблице без обозначения единиц.

`variantSkus` содержит артикулы модификаций, `variantStates` — видимость и наличие из экспорта. `combinations` отделяет существующие варианты от словаря известных числовых цен `price`.

Из исходных двух прайсов сохранены встроенные WebP-фото 32 панелей. У остальных используются ссылки из экспорта `f36f50a161b80f1ca24b4baa4fdd27a5.xlsx`: скачать их из среды пока мешает прокси. При временной ошибке загрузки фото показана плашка; товары без ссылки на фото исключены. Скрипты и формы из HTML-описаний не импортировались. Телефоны: +344985788787, +344955788787.

## Публикация

- GitHub: Settings → Pages → Deploy from a branch → main → / (root) → Save. После завершения публикации GitHub покажет адрес каталога.
- Netlify: ручное развёртывание папки с `index.html` или подключение GitHub-репозитория без команды сборки; каталог публикации — корень проекта (`.`).

HTTPS рекомендуется для работы кнопки копирования. Если доступ к буферу обмена запрещён, текст можно выделить и скопировать вручную.

## Проверено

344 импортированных строк сверены с веб-данными, 389 цен — с текстом фактического PDF. Проверяются основы, совместимость толщин, стеклосетка без утеплителя, отсутствие базальта, единицы измерения по разделам, копейки в ценах, сохранение выбора в hash и предупреждения о наличии. Внешние новые фото из среды не проверены из-за сетевой блокировки.

## Фирменный стиль

Оригинальные прозрачные PNG из `NASH-DVOR-brand-elements.zip` встроены в `CATALOG.brand`: `wordmark` (название со слоганом) и `symbol` (три полосы). Контуры не перерисованы. SVG только компонует изображения и ограничивает прозрачные поля при отображении; файлы PNG сохранены без изменения. Логотип показан в шапке и подвале, знак используется в декоре, плашках фото и значке вкладки.

Палитра из бренд-пакета: оранжевый #F45100, графит #202020, светлый фон #F5F1E8. Логотип сохраняет пропорции на экранах 320, 390, 768 и 1440 px. Все фирменные изображения внутри HTML; дополнительной папки с ресурсами для публикации не требуется.

## Печатный каталог

- `print/nash-dvor-catalog.pdf` — A4, 20 страниц в обычном порядке, с обложкой, оглавлением, четырьмя разделами и контактами. Все 54 панели; таблицы «основа × толщина» содержат 389 известных цен с единицами по разделам. 9 сочетаний польского клинкера со стеклосеткой без цены помечены тире; неподдерживаемые сочетания также обозначены тире.
- `print/nash-dvor-catalog-booklet-a3.pdf` — спуск полос: 10 сторон A3, 5 двусторонних листов для складывания в брошюру A4. Печатать на A3 в альбомной ориентации, 100%, с двусторонней печатью и переворотом по короткой стороне; дополнительный режим «брошюра» не включать. Первый разворот 20|1, оборот 2|19. Сначала полезно проверить один двусторонний лист.
- PDF использует 32 встроенных фото. У 22 новых позиций вместо недоступных из среды фото — QR на карточку сайта. Позиций без исходного фото больше нет. Для полноценной печати с фото всех панелей нужен архив недостающих фотографий.
- Новые разделы начинаются с новой страницы: керамогранит 3–8, польский клинкер 9–11, под покраску 12–15, имитация клинкера 16–19. Базальта нет.

Пересборка после изменения CATALOG: `python3 tools/build_print_catalog.py`. Нужны Python, ReportLab, PyMuPDF и Noto Sans или DejaVu Sans (в текущей среде установлены). Скрипт берёт данные из index.html, сохраняет оба PDF и `print/catalog-manifest.json` с проверяемым составом и порядком страниц. Веб-каталог содержит ссылку скачивания PDF в подвале.

## Отображение цен и мобильного заголовка

По просьбе владельца в веб-каталоге и обоих PDF не показываются даты цен и подписи «Ціну уточнюйте». Для неизвестной цены используется тире; числовые цены, единицы, основы и толщины сохранены. Даты происхождения данных остаются только в служебных исходниках и документации. Уведомления о наличии отдельных товаров сохранены.

Фраза «Матеріали для вашого дому» помещена в отдельный текстовый элемент с переносом и достаточной высотой строки. Проверено, что текст целиком помещается при ширинах 240, 280, 320, 390, 768 и 1440 px. Основа имитации клинкера оставлена без изменений по указанию владельца.

## Печать фотографий из браузера

`print/catalog-with-photos.html` — отдельная печатная версия из тех же данных, 20 страниц A4. Генератор: `python3 tools/build_print_html.py`. 32 фотографии встроены, 22 исходных URL загружаются непосредственно браузером посетителя, все позиции имеют исходное фото. Все цены и единицы сохранены.

Панель показывает фактическое число загруженных фото и включает кнопку «Зберегти PDF / Друк» после загрузки или ошибки всех изображений (таймаут 30 секунд). При печати браузер помещает загруженные изображения в PDF: переносить браузерную сессию или извлекать пароль не нужно. В диалоге выбирайте A4, масштаб 100%, поля «Немає», фон включён, колонтитулы выключены. Кнопка и счётчик не печатаются.

В текущей среде проверены 20 итоговых страниц A4, таблицы без переполнений, 54 товара и обработка сетевой ошибки 22 внешних фото. Успешная загрузка внешних фото здесь не заявляется: она происходит в пользовательском браузере. Предварительно сформированные PDF остаются отдельными файлами с прежними ограничениями изображений до получения исходников.

## Исключение позиций без фото

Из всех версий удалены TU-8310, TU-8810, TU-9010 и TU-9210: у них нет ни основного фото, ни галереи. Осталось 54 панели: 23 керамогранитные, 9 польского клинкера, 8 под покраску и 14 имитации. Цены и основы оставшихся позиций не изменены. Аудит активных модификаций содержит 344 строки, перечень исключённых артикулов сохранён отдельно в `excludedNoPhotoParents`.

Печатный каталог сохраняет 20 страниц и прежние диапазоны разделов; панели под покраску теперь размещены по две на странице. Веб-версия для печати ожидает загрузку 54 фото, без сообщения о четырёх отсутствующих изображениях.

Для PDF использованы 54 основные фотографии: QR-заменителей и отсутствующих фото в актуальном PDF больше нет. Названия, цвета и артикулы плитки взяты из текущего CATALOG. `tools/build_print_catalog.py --photo-cache /workspace/scratch/nashdvor-photos-68bbe7a` использует проверенные локальные исходники по manifest.json с контролем SHA-256. Изображения не перерисовываются и не меняются. Без флага генератор сохраняет прежний резервный сценарий для недоступных внешних фото. Кэш находится вне репозитория; для повторной сборки в другой среде нужно загрузить его исходные фото заново.

После изменения данных: пересобрать PDF с проверенным фотокэшем, выполнить `python3 tools/build_print_html.py`, затем `python3 tools/export_pdf_pages.py`, чтобы PDF, печатная HTML-версия, ZIP всех страниц и обзор были согласованы. Даты цен на клиентских страницах не показываются.
