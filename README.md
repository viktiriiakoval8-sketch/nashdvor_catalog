# Каталог «Наш двор»

Репозиторий проекта каталога «Наш двор».

## Текущее состояние

Создана начальная структура репозитория. Приложение, зависимости и автоматические тесты пока не добавлены; команды запуска и сборки появятся вместе с кодом проекта.

## Работа с проектом

Основная ветка — `main`.

```sh
git clone https://github.com/viktiriiakoval8-sketch/nashdvor_catalog.git
cd nashdvor_catalog
```

В облачной среде используйте существующий каталог `/workspace/nashdvor_catalog`. Повторное клонирование и создание Git worktree не требуются.

Не добавляйте в Git пароли, API-ключи и файлы `.env`. Когда приложению понадобятся переменные окружения, добавьте `.env.example` только с названиями и безопасными примерами значений.

## Следующий этап

Определить функции каталога и добавить исходный код приложения. После этого настроить установку зависимостей, запуск, сборку и тесты в облачной среде.
