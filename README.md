# Каталог термопанелей NASH DVOR

Один самостоятельный `index.html`: HTML, CSS и JavaScript без сборки и внешних скриптов. Интерфейс на украинском языке. Google Fonts необязательны: при отсутствии сети используются системные шрифты.

## Запуск

Откройте `index.html` в браузере или выполните из каталога проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

В облачной среде используйте существующий `/workspace/nashdvor_catalog`, не создавайте worktree и не клонируйте проект повторно.

## Данные

Все данные находятся в `const CATALOG` в начале скрипта. Инструкция над блоком объясняет добавление разделов, позиций, основ, толщин, цен, фото и контактов. Цены задаются ключами `основа_толщина`; отсутствующие сочетания отключены. `phone` — основной телефон, `phones` — дополнительные. Телефоны компании показаны в подвале. Формы заказа, запросы в мессенджеры и калькулятор площади удалены: это информационный каталог.

## Источники ассортимента

Каталог содержит 58 панелей в четырёх разделах: «Керамограніт» (23), «Клінкер · Польща» (9), «Під фарбування» (12), «Імітація клінкера» (14). Углы, откосы и посторонние товары из экспорта не включены.

Источники:

- Два пользовательских XLSX «Термопанели керамограніт — родительские артикулы.xlsx» и «Термопанели польша — клинкер с артикулами.xlsx»: исходные 32 позиции, 160 цен за м² от 01.09.2026 и 33 встроенные WebP-фотографии.
- Экспорт Хорошопа `f36f50a161b80f1ca24b4baa4fdd27a5.xlsx`: названия, дополнительные разделы, ссылки на фотографии и характеристики. Отдельных строк модификаций в нём нет. Скрипты и формы из HTML-описаний не импортировались.

Базальтовая вата полностью исключена по прямому указанию владельца: компания её не производит. У всех панелей доступен пенопласт; у польского клинкера добавлена стекловолоконная сетка без утеплителя (mm=0), с неизвестной ценой. Сетка подтверждена текстом описания, а не отдельной строкой модификации.

У панелей под покраску показаны толщины 20/30/40/50/80/100/120/150/200 мм из описания; цена за м² известна только для 20 мм. Четыре скрытые в экспорте позиции сохранены для просмотра с пометкой «Наявність уточнюйте», без опубликованной цены. У имитации клинкера экспорт подтверждает только пенопласт 50 мм за 990 грн/м².

Цены из экспорта за штуку не заменяют старые цены за м². Дата актуальности новых цен в экспорте отсутствует — это прямо указано в карточках. Не создавайте цены для отсутствующих сочетаний: используйте «Ціну уточнюйте». Массив `combinations` задаёт варианты, которые можно просматривать, отдельно от словаря известных числовых цен `price`.

Новые фотографии подключены URL из экспорта: доступ к nashdvor.com.ua в среде блокируется прокси, поэтому скачать и встроить их пока невозможно. В браузере клиента они загружаются непосредственно с сайта; ошибки заменяются плашкой. У четырёх скрытых панелей фото в экспорте нет. Первоначальные 33 фотографии остаются внутри HTML.

Название и цвет для первых 32 панелей обновлены по экспорту; старые прайсовые артикулы и коды производителя сохранены. Телефоны: +380985788787, +380955788787.

## Публикация

- GitHub: Settings → Pages → Deploy from a branch → main → / (root) → Save. После завершения публикации GitHub покажет адрес каталога.
- Netlify: ручное развёртывание папки с `index.html` или подключение GitHub-репозитория без команды сборки; каталог публикации — корень проекта (`.`).

HTTPS рекомендуется для работы кнопки копирования. Если доступ к буферу обмена запрещён, текст можно выделить и скопировать вручную.

## Проверено

Браузерные проверки покрывают 58 карточек, четыре раздела, отсутствие базальтовой ваты, переключение пенопласт/сетка без утеплителя, просмотр варианта без цены, девять толщин панелей под покраску, пометку скрытых позиций, восстановление состояния через hash и замену недоступных новых фото. Ранее для исходных 32 панелей проверены все 160 цен и загрузка встроенных фото. Реальная загрузка внешних новых фото из этой среды не подтверждена из-за сетевого ограничения.

## Фирменный стиль

Оригинальные прозрачные PNG из `NASH-DVOR-brand-elements.zip` встроены в `CATALOG.brand`: `wordmark` (название со слоганом) и `symbol` (три полосы). Контуры не перерисованы. SVG только компонует изображения и ограничивает прозрачные поля при отображении; файлы PNG сохранены без изменения. Логотип показан в шапке и подвале, знак используется в декоре, плашках фото и значке вкладки.

Палитра из бренд-пакета: оранжевый #F45100, графит #202020, светлый фон #F5F1E8. Логотип сохраняет пропорции на экранах 320, 390, 768 и 1440 px. Все фирменные изображения внутри HTML; дополнительной папки с ресурсами для публикации не требуется.

## Печатный каталог

- `print/nash-dvor-catalog.pdf` — A4, 20 страниц в обычном порядке, с обложкой, оглавлением, четырьмя разделами и контактами. Все 58 панелей; таблицы «основа × толщина» содержат 182 известные цены за м². 109 подтверждённых сочетаний без цены помечены «Уточн.», неподдерживаемые — тире.
- `print/nash-dvor-catalog-booklet-a3.pdf` — спуск полос: 10 сторон A3, 5 двусторонних листов для складывания в брошюру A4. Печатать на A3 в альбомной ориентации, 100%, с двусторонней печатью и переворотом по короткой стороне; дополнительный режим «брошюра» не включать. Первый разворот 20|1, оборот 2|19. Сначала полезно проверить один двусторонний лист.
- PDF использует 32 встроенных фото. У 22 новых позиций вместо недоступных из среды фото — QR на карточку сайта, у четырёх отсутствуют фото в исходнике и стоит фирменная плашка. Для полноценной печати с фото всех панелей нужен архив недостающих фотографий.
- Новые разделы начинаются с новой страницы: керамогранит 3–8, польский клинкер 9–11, под покраску 12–15, имитация клинкера 16–19. Базальта нет.

Пересборка после изменения CATALOG: `python3 tools/build_print_catalog.py`. Нужны Python, ReportLab, PyMuPDF и Noto Sans или DejaVu Sans (в текущей среде установлены). Скрипт берёт данные из index.html, сохраняет оба PDF и `print/catalog-manifest.json` с проверяемым составом и порядком страниц. Веб-каталог содержит ссылку скачивания PDF в подвале.
