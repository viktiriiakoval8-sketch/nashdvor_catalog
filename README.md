# Каталог термопанелей NASH DVOR

Один самостоятельный `index.html`: HTML, CSS и JavaScript без сборки и внешних скриптов. Интерфейс на украинском языке. Google Fonts необязательны: при отсутствии сети используются системные шрифты.

## Запуск

Откройте `index.html` в браузере или выполните из каталога проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

В облачной среде используйте существующий `/workspace/nashdvor_catalog`, не создавайте worktree и не клонируйте проект повторно.

## Данные

Все данные находятся в `const CATALOG` в начале скрипта. Инструкция над блоком объясняет добавление разделов, позиций, основ, толщин, цен, фото и контактов. Цены задаются ключами `основа_толщина`; отсутствующие сочетания отключены. `phone` — основной телефон, `phones` — дополнительные. Телефоны компании показаны в подвале. Формы заказа, запросы в мессенджеры и калькулятор площади удалены: это информационный каталог.

## Источники ассортимента

Данные взяты из двух предоставленных пользователем XLSX, прайс от **01.09.2026**:

- «Термопанели керамограніт — родительские артикулы.xlsx»: 23 позиции, раздел «Керамограніт».
- «Термопанели польша — клинкер с артикулами.xlsx»: 9 позиций, раздел «Клінкер · Польща».

Перенесены все 160 цен для толщин 50, 80, 100, 150 и 200 мм, родительские артикулы, артикулы сайта, коды производителей и ссылки на карточки сайта. 33 фотографии извлечены с привязкой к строкам таблицы и встроены в CATALOG в формате WebP. В одном товаре две фотографии. Внешние фото и скрипты не требуются; весь каталог — один HTML около 2,4 МБ.

При расхождениях не исправляли исходные данные наугад: заголовок — из столбца «Назва на сайті», поле «Колір за прайсом» — из столбца «Колір». Например, Baker Street имеет название «Коричневий», но цвет «бежевий» в прайсе. Разделы сохранены по названиям исходных файлов, даже если URL карточки содержит слово «клинкер».

В таблицах одна сетка цен; ссылки на карточки указывают основу «пінопласт». Другие основы и цены для них не выдумывались. `available` означает наличие варианта в прайсе, а не подтверждённый остаток на складе. Телефоны пользователя: +380985788787, +380955788787.

Это полный ассортимент из предоставленных таблиц; полнота относительно всего сайта не подтверждена, поскольку прокси среды пока блокирует nashdvor.com.ua.

## Публикация

- GitHub: Settings → Pages → Deploy from a branch → main → / (root) → Save. После завершения публикации GitHub покажет адрес каталога.
- Netlify: ручное развёртывание папки с `index.html` или подключение GitHub-репозитория без команды сборки; каталог публикации — корень проекта (`.`).

HTTPS рекомендуется для работы кнопки копирования. Если доступ к буферу обмена запрещён, текст можно выделить и скопировать вручную.

## Проверено

В Chromium проверены все 32 позиции, загрузка каждого главного фото и все 160 цен для пяти толщин. Дополнительно проверены разделы, артикулы, ссылки на сайт, восстановление варианта из hash после перезагрузки, копирование ссылки, мобильная/настольная ширина и отсутствие ошибок JavaScript. Заказать панели через каталог нельзя.
