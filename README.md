# Каталог термопанелей NASH DVOR

Один самостоятельный `index.html`: HTML, CSS и JavaScript без сборки и внешних скриптов. Интерфейс на украинском языке. Google Fonts необязательны: при отсутствии сети используются системные шрифты.

## Запуск

Откройте `index.html` в браузере или выполните из каталога проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

В облачной среде используйте существующий `/workspace/nashdvor_catalog`, не создавайте worktree и не клонируйте проект повторно.

## Данные

Все данные находятся в `const CATALOG` в начале скрипта. Инструкция над блоком объясняет добавление разделов, позиций, основ, толщин, цен, фото и контактов. Цены задаются ключами `основа_толщина`; отсутствующие сочетания отключены. `phone` — основной телефон, `phones` — дополнительные. Telegram требует имени аккаунта; Viber — подтверждённого номера. Телефонный звонок не поддерживает заполнение текста; для Viber предусмотрено копирование запроса.

**Разделы, позиции и цены пока демонстрационные.** Полный перечень с nashdvor.com.ua не проверен из-за блокировки сайта прокси среды. Фото не предоставлены. Телефоны указаны пользователем: +380985788787, +380955788787. Не отключайте `demo`, пока реальные данные не проверены.

## Публикация

- GitHub: Settings → Pages → Deploy from a branch → main → / (root) → Save. После завершения публикации GitHub покажет адрес каталога.
- Netlify: ручное развёртывание папки с `index.html` или подключение GitHub-репозитория без команды сборки; каталог публикации — корень проекта (`.`).

HTTPS рекомендуется для работы кнопки копирования. Если доступ к буферу обмена запрещён, текст можно выделить и скопировать вручную.

## Проверено

В Chromium проверены мобильная и настольная ширина, переключение разделов и позиций, варианты цен, недоступные сочетания, расчёт площади с десятичной запятой, некорректный ввод, восстановление выбора из hash после перезагрузки, обе телефонные ссылки, недоступный товар и подмена битого фото. Фактическая отправка запросов в мессенджеры не проверена: аккаунты не предоставлены.
